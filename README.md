## 🧑‍💻 Getting Started

### Clone the repo
```bash
git clone https://github.com/im-ghost/mangmang.git
cd mangmang
```

### Install dependencies
```bash
yarn
```

### Start JSON Server
```bash
yarn server
```

### Run the app
```bash
yarn dev
```

## 🌐 Deployment (Netlify)

1. Push to GitHub  
2. Connect repository to Netlify  
3. Build command:
   ```
   yarn build
   ```
4. Publish directory:
   ```
   dist
   ```
